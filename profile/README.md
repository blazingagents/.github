Blazing Agents provides managed execution, secure Workspaces, tools, skills,
tasks, observability, and usage tracking—so developers can focus on agent
logic instead of platform infrastructure.

## SDKs

| Language | Repository | Install |
| --- | --- | --- |
| TypeScript | [`blazingagents/typescript-sdk`](https://github.com/blazingagents/typescript-sdk) | `npm install @blazing-agents/sdk` |
| Python | [`blazingagents/python-sdk`](https://github.com/blazingagents/python-sdk) | `pip install blazing_agents` |
